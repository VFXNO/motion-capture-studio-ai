GVHMR model setup.

A video-sequence body model from Zhejiang University's 3D Vision Group. Runs locally on a GPU, separately from the browser engine.

Not running in the browser yet.

The studio's Extract motion button runs the selected engine: automatic RTMW3D-X by default, or MediaPipe when chosen. GVHMR is separate and uses the command below after you provide licensed files. There is no silent fallback or cloud upload.

Basic AMD GPU operators and headless imports have been tested. Pretrained GVHMR inference on this machine is not verified until all checkpoints are supplied and a real capture succeeds.

Body and root only. GVHMR does not supply articulated fingers or facial expressions, and existing hand/face captures are not automatically merged.

1 / Review licenses and get the files.

GVHMR's published license is research/non-commercial. Body models and component weights have their own terms. Framecraft cannot accept them for you.

  • GVHMR license
  • SMPL-X registration/download — neutral NPZ body model
  • Official GVHMR checkpoint downloads — GVHMR, HMR2.0a, ViTPose huge, YOLOv8x

Place the five files under .third-party/GVHMR/inputs/checkpoints/ as described in the full setup checklist ↓. No account credentials are needed by this app.

2 / Check the local environment.

Open PowerShell in your motion-capture-studio folder:

.venv-gvhmr\Scripts\python.exe tools/gvhmr.py doctor --probe

The doctor lists missing files and tests GPU operations/imports. Passing prerequisites is not proof that pretrained inference or accuracy has been verified.

3 / Capture, then import into Blender.

.venv-gvhmr\Scripts\python.exe tools/gvhmr.py run 'input.mp4' 'new-dance.gvhmr.json' --static-camera --accept-noncommercial --trust-checkpoints

Read the checklist before using the acknowledgement flags. Pickle checkpoints can execute code; use only trusted official files. Omit --static-camera if the camera moves. Use one performer, up to 60 seconds. Input timestamps are resampled to 30 fps.

Import the new .gvhmr.json with the updated Blender importer ↓. Native body rotations and world travel are preserved; originals are not overwritten. Character retargeting remains separate.
