The script handles setup for you

On first capture, the studio creates an isolated Python environment, installs the AI dependencies, and downloads about 463 MB of checksum-verified models. Later captures reuse them. No Git or Node.js installation is needed for the studio workflow.

Windows with Python 3.12 is required. Double-click Launch Studio.bat to start the local service. Blender must be installed for automatic .blend creation; it runs in a fresh background process and does not touch your open scenes. You can also download capture JSON.

Progress and cancellation are built into the studio. Your selected video is sent only to this PC's loopback server, never to a cloud service. Setup downloads model/code packages, not your footage.

What you get

Body and finger animation, a native 68-point face wire mesh, and estimated floor travel. No expression scores or ready-made character face rig. Character retargeting is separate.

Use one clearly visible full-body performer, a fixed camera, flat floor and a clip up to 60 seconds. Height, FOV and tilt have usable defaults but are approximate calibration inputs.

Absolute scale and travel are still estimated. No learned world trajectory, camera-motion compensation, bone twist or guaranteed accuracy improvement. The engine selector shows what actually runs; MediaPipe is now an explicit alternative, not a silent fallback.
